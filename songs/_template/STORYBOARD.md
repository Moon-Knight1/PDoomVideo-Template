# 分镜表（施工图）

先填这张表，再去写代码。一句话歌词对应一个镜头，右边写"画面里发生什么"。

## 规则

1. **每镜必须有事发生**——有人做动作、有东西坏掉/变形/追上来。
2. **一镜 2–4 秒**，超了就拆成两个动作。
3. **转场由动作完成**：被吞掉、掉下去、镜头穿过眼睛、东西砸向镜头；不要靠淡入淡出。
4. **不要直译歌词**——"孤独"不要画一个人坐着，要让他伸手去够一个够不着的东西。
